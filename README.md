# MarketLens — Phase 2

## 1. Project Overview
MarketLens is a web-based marketing intelligence dashboard developed to help users organize competitor information and analyze social media marketing trends. It aims to simplify competitor comparison by presenting information such as competitor details, post performance, engagement and trending topics in one place.

## 2. Technologies Used
- **Frontend:** React
- **Backend:** Java Spring Boot
- **Database:** MySQL
- **Communication:** REST APIs
- **Version Control:** Git and GitHub

## 3. Implementation
- Developed the React dashboard and application pages.
- Established basic communication between React and Spring Boot.
- Started MySQL integration for competitor data.
- Demonstrated competitor data retrieval through the backend.
- Continued improving application functionality and user interface.

## 4. System Workflow
1. The user interacts with the React dashboard.
2. React sends requests to the Spring Boot REST APIs.
3. The backend communicates with MySQL.
4. The response is displayed on the dashboard.
