Project Description

Market Lens is a web-based dashboard created to make social media marketing analysis easier. It brings useful information about market trends and competitors into one place, so users do not have to check different sources manually.

The dashboard helps users see what topics are trending, compare competitor activities and understand which content is getting more engagement. Searching, sorting and ranking algorithms are used to keep the data organized and make important information easier to find.

The application is developed using React for the frontend, Java Spring Boot for the backend and MySQL for storing data. WebSockets are used for live updates while Docker helps the application run smoothly across different systems.

The main purpose of Market Lens is to save time and present marketing information in a clear and simple way so that users can understand trends and competitor performance more easily.
